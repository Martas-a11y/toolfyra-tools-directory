# Toolfyra Tools Directory

**Canonical site: [toolfyra.com](https://toolfyra.com)**

A curated directory of the free, privacy-first tools available on Toolfyra.
Every tool runs entirely in your browser — no uploads, no signup, no tracking
of your files.

## Why client-side?

Files and inputs stay on your device. Passwords, documents, photos and
financial numbers you paste into a Toolfyra tool are never sent to a server.
